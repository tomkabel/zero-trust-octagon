Axiom 7: unattested data may only deny, never grant. Each input below is classified by what it can do to a sovereignty verdict. **GRANT-capable** inputs are cryptographically verifiable and revocable by a supervisory body. **DENY-only** inputs are contracts, declarations, or revocable administrative acts: they can fail a claim, never pass one. **Allowlist only** inputs gate which components are admissible and never act as a runtime grant.
